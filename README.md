# OrbitalPearl

OrbitalPearl is a Minecraft plugin designed to enhance gameplay by allowing players to bind multiple players to a special fishing rod. When the rod is used, all bound players are instantly teleported to the rod user, accompanied by unique sound effects and a series of potion effects. This plugin is perfect for servers looking to add a unique and engaging feature to their gameplay.

## Install

1. Download the plugin JAR file from the GitHub repository.
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart or reload your server to load the plugin.

## Use

1. Hold a fishing rod in your main hand.
2. Use the command `/orbitalpearl <player>` to bind a player to your fishing rod. Replace `<player>` with the name of the player you want to bind.
3. Repeat the command to bind multiple players to the same rod.
4. When you use the fishing rod, all bound players will be teleported to your location and receive the specified potion effects.
